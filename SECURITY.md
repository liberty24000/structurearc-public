# Sécurité

Signaler une vulnérabilité **en privé** (onglet *Security* de ce dépôt, « Report a vulnerability »), pas dans un ticket public.

Périmètre : application de bureau locale ; les données restent sur l'ordinateur ; aucune télémétrie. Les installateurs publiés sont signés ; vérifiez toujours la signature et l'empreinte (voir [VERIFIER.md](VERIFIER.md)).
