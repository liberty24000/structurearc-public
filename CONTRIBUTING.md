# Contribuer

Ce dépôt ne contient **aucun code source** : il publie les installateurs, la présentation et les notes de version de StructureArc. Les contributions de code ne sont donc pas acceptées ici.

Vous pouvez en revanche **ouvrir un ticket** (onglet *Issues*) pour signaler un problème, poser une question ou proposer une idée. Pour un problème de sécurité, n'ouvrez **pas** de ticket public : voir [SECURITY.md](SECURITY.md).

Joignez, si possible : la version de StructureArc, la version de Windows, la quantité de mémoire de l'ordinateur, la carte graphique, et les étapes pour reproduire. N'envoyez jamais de clé, mot de passe ou document confidentiel.
