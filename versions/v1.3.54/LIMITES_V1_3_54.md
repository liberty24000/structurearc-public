# Limites connues — StructureArc 1.3.54

Les reprises et le suivi des fragments améliorent l’exécution des modèles locaux, mais un projet complet n’est pas encore qualifié sur Qwen3.5 4B. Lors du dernier essai, trois fichiers sont créés, mais les tests restent incomplets et la documentation manque ; le contrôle indépendant échoue. Une réponse acceptée par le moteur ne prouve pas la réussite de la mission.

Les reprises structurées s’appliquent au moteur local dont le format et le comptage ont été vérifiés. Les autres moteurs conservent leur parcours compatible. Les contrôles de fichiers, de permissions, de mémoire et les demandes d’arrêt restent effectifs.

La conservation du contexte a été observée sur des essais précis ; elle ne garantit ni un raisonnement correct ni la réussite sur tous les modèles. Les tests ignorés et les parcours non exécutés ne sont pas présentés comme validés.

Aucun nouveau contrôle physique Android ni essai vocal réel n’est revendiqué dans cette version. Les projets personnels, les clés API et les conversations ne font pas partie de l’installateur public. Les ressources vocales et les données d’une installation existante doivent être conservées lors de la mise à jour.
