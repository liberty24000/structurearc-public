# Limites — StructureArc 1.3.36

- Installation Android Chrome encore à confirmer sur téléphone physique. Les contrôles HTTPS du PC ne prouvent pas la confiance du téléphone envers son certificat local.
- Une demande acceptée par Chrome n’est pas une preuve d’installation. Les erreurs de génération ou d’installation du paquet Android ne sont pas toutes exposées au site ; relever leur texte exact reste nécessaire.
- Aucun certificat perpétuel ni contournement des vérifications HTTPS. L’autorité locale est conservée, les certificats serveur sont renouvelés par l’application.
- Le budget de mémoire engagée reste une estimation adaptée au contexte. Les modèles peuvent encore échouer ; aucune qualification générale de projet autonome n’est annoncée.
- La voix utilise Whisper base français par segments et une voix Windows. Qualité acoustique Android et interruption avec écho encore à éprouver sur matériel réel ; Moshi/Kyutai non intégré.
- Les diagnostics sont bornés et peuvent être perdus lorsque le navigateur se ferme, que le PC est injoignable ou que le stockage échoue. Aucun journal exhaustif sans exception n’est garanti.
