# Limites 1.3.42

Le rejet de l’événement de reconnaissance est corrigé et couvert par une régression ciblée. Un test du serveur seul ne suffit pas à prouver le fonctionnement du navigateur; les preuves de cette version distinguent ces parcours.

Le gain de contexte concerne les échanges sociaux explicites. Essai synthétique avec les vrais modèles locaux : premier jeton de salutation en 208 / 348 / 960 ms sur 0,5B / 1,5B / 4B; voix simultanée et téléphone physique exclus de ce banc. Les petits modèles conservent des limites de compréhension.

Le délai complet réellement entendu sur Android reste à confirmer après installation. Moshi exige des ressources GPU; les packs vocaux sont séparés de l’installateur. Les phases M1–M4 de qualification de l’autonomie restent ouvertes.
