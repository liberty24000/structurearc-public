# StructureArc 1.3.48

Après une réponse locale interrompue ou un lot d'outils incomplet, la reprise existante demande désormais un seul appel à la fois, sans réflexion supplémentaire. Après une réponse complète, le profil normal du modèle est rétabli. Les outils autorisés restent disponibles ; aucun outil d'une réponse rejetée n'est exécuté.

Les erreurs de sortie incomplète contiennent désormais des compteurs de texte, de réflexion et d'arguments pour faciliter le diagnostic. Le contenu de ces fragments rejetés n'est pas enregistré dans ces événements.

Cette version conserve la navigation mobile, le chat général, les précisions transmises aux agents suivants et la voix française féminine Kyutai locale. Les projets, conversations, clés, certificats et modèles personnels ne sont pas inclus dans l'installateur.

La réalisation autonome d'un projet complet par tout modèle local n'est pas qualifiée. Consultez LIMITES_V1_3_48.md et les preuves de livraison.
