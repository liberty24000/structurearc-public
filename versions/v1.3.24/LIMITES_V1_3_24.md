# Limites de StructureArc V1.3.24

La correction de Sonnet 5.5 ne prouve pas que tous les modèles et tous les outils fonctionnent. Le test réel de deux outils est un diagnostic borné, pas la réalisation autonome d’un projet complet. Les essais d’autonomie 12 à 15 restent des échecs ; aucune requalification en succès.

Le choix du raisonnement repose sur les capacités annoncées par le fournisseur. Un modèle non pris en charge, un accès refusé ou une panne reste signalé et bloque le parcours concerné. L’essai réel Opus 5.5 a reçu un refus du fournisseur ; les modes adaptatifs et flux signés disposent de tests synthétiques, pas d’une preuve réelle de réussite pour tous les modèles.

Le contrôle Claude est une petite requête facturable acceptée à un instant donné. Il ne donne pas de solde exact, ne réserve pas de budget et ne garantit pas les fonds nécessaires jusqu’à la fin d’un projet. Le cache positif est borné ; un refus ultérieur interrompt les appels concernés.

Le raisonnement privé des modèles cloud n’est pas affiché comme un journal du « subconscient » et son nombre de caractères n’est pas mesuré par cette version. Les blocs signés du tour actif restent seulement en mémoire native pour respecter le protocole des outils ; leur présence n’est pas une preuve de meilleure décision.

Moshi/Kyutai n’est pas intégré. Aucun essai acoustique de conversation bidirectionnelle avec interruption ni test physique sur téléphone n’est revendiqué. L’accès réseau suppose le PC et l’application ouverts, le certificat approuvé et l’appareil appairé. Le certificat local existant reste refusé par le profil supplémentaire VERIFY_X509_STRICT de Python 3.13 (Authority Key Identifier absent). Aucun changement de confiance système ou de pare-feu.

L’auto-amélioration suppose un dossier source présent et autorisé comme projet. Une clé API n’accorde pas cet accès. L’installateur public ne fournit pas le code source privé, les projets ou les secrets du propriétaire. La préparation d’une copie isolée n’est pas un parcours automatique de livraison complet depuis le chat.
