# Limites connues — StructureArc 1.3.58

Les essais réels Qwen3.5 4B et Qwopus 9B produisent des programmes invalides et ne livrent ni tous les tests ni la documentation demandés. Les vérificateurs indépendants échouent, sans réparation des livrables par le réviseur. Le 9B démarre maintenant dans les conditions mesurées du poste ; cela ne garantit pas son admission avec toute charge mémoire.

Régression native : 1 160 réussites, 26 tests explicitement ignorés. Les 557 tests d’interface précédents portent sur des sources d’interface identiques, contrôlées par empreinte. Le nouveau test reproduit une perte de précision puis vérifie trois compressions avec conservation du texte complet et de son ordre.

Le comptage exact est disponible sur le moteur local reconnu b11643. Le cloud utilise un budget applicatif prudent et une estimation. Des instructions indispensables trop longues restent une erreur explicite ; elles ne sont pas supprimées pour annoncer une réussite. La persistance de tous les contrôles échoués entre reprises d’agents reste à renforcer.

Aucun nouvel essai Android physique ou acoustique n’est revendiqué. Les voix locales restent inchangées. L’installateur ne contient pas de projets personnels, conversations, mémoires, certificats privés ni clés API.
